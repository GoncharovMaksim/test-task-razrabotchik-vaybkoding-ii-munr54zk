# О-комплекс: ИИ-Ассистент менеджера AmoCRM

Production-ready сервис и интерфейс интеграции для AmoCRM на **TypeScript**, разработанный специально по ТЗ компании **"О-комплекс"**.

Сервис принимает обращение клиента в диалоговом окне сделки, сопоставляет его со структурированной базой регламентов и цен компании, после чего возвращает два блока:
1. **Вежливый ответ клиенту** — выверенное обращение с опорой на реальные регламенты и прайс-лист "О-комплекс", без галлюцинаций, с релевантным Call to Action.
2. **Подсказку по допродажам для менеджера** — выделение триггера боли клиента, ценностное обоснование, расчет потенциала прироста чека и готовая реплика-пивот для менеджера.

## 1. Архитектура и ключевые модули

```
┌────────────────────────────────────────────────────────┐
│                   AmoCRM Dialogue Window               │
│ (Чат со сделкой, контекст лида, быстрые сценарии, ввод)│

                            │ POST /api/assist
                            ▼
┌────────────────────────────────────────────────────────┐
│                   Next.js App Router                   │
│   (Zod Validation, Error Isolation, Token Masking)     │
└──────────────┬────────────────────────────┬────────────┘
               │                            │
               ▼                            ▼
┌───────────────────────────┐  ┌─────────────────────────┐
│   KnowledgeBaseService    │  │   UpsellEngineService   │
│(Поиск по базе регламентов,│  │(Матрица триггеров боли, │
│  нормализация токенов 1C) │  │  допродажи и LTV boost) │
└──────────────┬────────────┘  └────────────┬────────────┘
               │                            │
               └─────────────┬──────────────┘
                             ▼
              ┌─────────────────────────────┐
              │    AiAssistantService       │
              │  (Multi-Provider Failover)  │
              └──────────────┬──────────────┘
                             │
     ┌───────────────────────┼───────────────────────┐
     ▼                       ▼                       ▼
┌──────────────┐      ┌──────────────┐      ┌─────────────────┐
│   Groq API   │      │  Gemini API  │      │  Deterministic  │

│  LPU 80ms)   │      │  Fallover)   │      │  (Zero-Downtime)│

```

1. **Frontend / Рабочее место менеджера**:
   - Полноценная симуляция карточки сделки и диалогового окна AmoCRM (ООО «СеверТрейд», воронка, бюджет, теги, переписка).
   - Предустановленные типовые сценарии обращений («Интеграция 1С и остатки склада», «Потеря ночных заявок / AI-квалификатор», «Базовое внедрение AmoCRM», «Телефония и записи звонков»).
   - Интерактивный виджет Copilot с копированием в 1 клик, вставкой в поле ввода менеджера и переключением AI-провайдеров.
2. **База знаний ([`knowledge-base.ts`](file:///hanterpro_test_tasks/test-task-razrabotchik-vaybkoding-ii-munr54zk/src/lib/kb/knowledge-base.ts))**:
   - Точные регламенты, сроки и стоимость услуг "О-комплекс" (внедрение AmoCRM от 45 000 ₽, интеграция 1С от 60 000 ₽, AI-боты от 35 000 ₽, телефония от 25 000 ₽, кастомные виджеты от 30 000 ₽).
   - Алгоритм ранжирования с нормализацией токенов (поддержка кириллицы/латиницы 1С/1C, учет весов тегов и заголовков).
3. **Матрица допродаж ([`upsell-rules.ts`](file:///hanterpro_test_tasks/test-task-razrabotchik-vaybkoding-ii-munr54zk/src/lib/kb/upsell-rules.ts))**:
   - Выявление скрытых болей клиента и подбор комплементарного продукта с расчетом LTV и готовой фразой-пивотом.
4. **Отказоустойчивый диспетчер ([`ai-service.ts`](file:///hanterpro_test_tasks/test-task-razrabotchik-vaybkoding-ii-munr54zk/src/lib/ai/ai-service.ts))**:
   - Основной инференс: **Groq API** (`qwen/qwen3.8-27b`) со сверхбыстрым ответом.
   - Резервный провайдер: **Google Gemini API** (`gemini-2.5-flash`).
   - Автономный **Deterministic Rule Engine**: локальный алгоритмический движок, гарантирующий 100% аптайм и моментальный ответ даже при отказе внешних LLM API.
5. **AmoCRM Webhook Receiver ([`route.ts`](file:///hanterpro_test_tasks/test-task-razrabotchik-vaybkoding-ii-munr54zk/src/app/api/amocrm/webhook/route.ts))**:
   - Прием стандартных вебхуков от Salesbot / Digital Pipeline AmoCRM, фильтрация исходящих сообщений для предотвращения зацикливания.

## 3. Запуск проекта

### Вариант 1: Запуск в Docker Compose одной командой
```bash
docker compose up -d --build
```
Приложение станет доступно по адресу `http://localhost:3000`.

### Вариант 2: Локальный запуск (Node.js 20+)
```bash
npm install
npm test            # запуск набора из 31 теста
npm run type-check  # проверка строгой типизации TypeScript
npm run dev         # запуск локального сервера разработки (порт 3000)
```
