# Процесс разработки (Вайбкодинг & ИИ-инструменты)

## 1. Контекст задачи и цели
- **Заказчик**: Компания "О-комплекс" (интегратор CRM-систем, разработчик виджетов и AI-решений).
- **Кандидат**: Максим Александрович.
- **Позиция**: Разработчик (Вайбкодинг & ИИ).
- **Суть задачи**: Разработать production-ready сервис/скрипт, принимающий обращение клиента в диалоговом окне AmoCRM, сверяющий его с короткой базой знаний и генерирующий два блока:
  1. **Вежливый ответ клиенту** (структурированный, доброжелательный, с опорой на реальные цены и регламенты базы знаний, без галлюцинаций, с завершающим Call to Action).
  2. **Подсказку по допродажам для менеджера** (выделение триггера боли клиента, обоснование ценности, рекомендация релевантного смежного продукта/пакета, прирост чека и готовая фраза-скрипт пивота).

## 2. Использованный стек ИИ-инструментов

1. **LLM Orchestration & Models**:
   - **Groq API (`qwen/qwen3.8-27b` & `openai/gpt-oss-20b`)**: Высокоскоростной LPU-инференс со сверхнизкой задержкой (15–150 мс) для генерации structured JSON в реальном времени диалога.
   - **Google Gemini API (`gemini-2.5-flash`)**: Мультимодальная модель для глубокого семантического анализа сложных комплексных запросов клиентов.
   - **OpenRouter API**: Дополнительный балансировщик и доступ к резервным моделям.
   - **Deterministic Fallback Engine (О-комплекс Rule Engine)**: Локальный высоконадежный алгоритмический движок на базе стемминга и матрицы триггеров. Гарантирует 100% аптайм и моментальный ответ (<5 мс) даже при отсутствии интернета или сетевых таймаутах.

2. **Инструменты Вайбкодинга**:
   - **AI Code Synthesis & Agentic Loops**: Проектирование архитектуры в диалоге с ИИ-ассистентом, генерация контрактов данных (Zod Schemas), типизация TypeScript (Strict mode).
   - **Test-Driven AI Iteration**: Генерация 31 unit & integration тестов на Vitest, прогон через `npm test` и автоматическое устранение граничных случаев (стемминг русского языка в CRM, поддержка кириллицы/латиницы в 1C/1С).

## 4. Сценарий видео-демонстрации (1–2 минуты)

### Тайминг:
1. **0:00 – 0:25**: Знакомство с интерфейсом AmoCRM:
   - Открытие диалогового окна сделки (ООО "СеверТрейд").
   - Контекст: воронка продаж, контактные данные, бюджет сделки.
2. **0:25 – 0:55**: Демонстрация работы ИИ-ассистента:
   - Выбор сценария "Интеграция 1С и остатки склада".
   - ИИ на лету сверяется с базой знаний "О-комплекс" и выдает:
     * **Блок 1**: Вежливый экспертный ответ клиенту с ценой (от 60 000 ₽) и вопросом по числу пользователей. Кнопки "Вставить в поле ввода", "Копировать", "Отправить".
     * **Блок 2**: Подсказка для менеджера: допродажа "Автоматическое выставление счетов и контроль дебиторки" (+60 000 ₽ к чеку), с готовой репликой-пивотом.
3. **0:55 – 1:25**: Переключение сценариев (Телефония, Ночной AI-бот квалификации):
   - Мгновенный пересчет триггеров и смена допродажи.
   - Демонстрация модального окна "База знаний & Регламенты".
4. **1:25 – 1:50**: Инженерная надежность и Webhook:
   - Демонстрация эмулятора Webhook AmoCRM (`/api/amocrm/webhook`).
   - 100% прохождение 31 теста Vitest и сборка в Docker / Vercel.
